# Data

This directory contains the data files and data-related documentation used in the project.

Planned subdirectories:

- `raw/`: Original Elliptic++ CSV files downloaded from the official source.
- `processed/`: Cleaned or transformed datasets generated by the project pipeline.

The following raw files are required:

- `txs_features.csv`
- `txs_classes.csv`
- `txs_edgelist.csv`

The raw and processed data files are not uploaded to GitHub because of their file sizes. Each user should download the original files and place them in the appropriate local directory.
